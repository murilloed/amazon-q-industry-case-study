# Focus-Group Protocol

## Participants

- three developers experienced in software development and code review;
- one researcher acting as facilitator.

## Session

Approximate duration: one hour.
Pilot session date: 2026-04-01.

1. Introduction to the research purpose and session rules.
2. Presentation of the Merge Request and generated documentation.
3. Individual review of ten selected Java classes, including their methods.
4. Registration of comments in GitLab.
5. Guided discussion using open and progressively deeper questions.
6. Closing synthesis.

## Facilitator Principles

- avoid inducing answers;
- do not defend the evaluated solution;
- practice active listening;
- request examples and counterexamples; and
- distinguish participant statements from researcher interpretation.

## Evaluation Dimensions

- clarity;
- correctness;
- usefulness;
- consistency;
- language;
- documentation scope;
- review effort;
- trust; and
- adoption potential.
