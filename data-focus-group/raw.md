# Raw

## Raw Experimental Data — Focus Group Evaluation

---

# Overview

This section contains the raw and unprocessed data collected during the execution of the focus group conducted as part of the Master's Degree research project on automated documentation using Large Language Models (LLMs).

The purpose of this directory is to preserve the original empirical evidence generated throughout the experiment before analytical interpretation, categorization, or transformation.

These artifacts represent the primary source material used during:

- qualitative analysis;
- quantitative analysis;
- thematic categorization;
- integrated scientific interpretation.

---

# Purpose of the Raw Data

The raw data repository was created to ensure:

- methodological transparency;
- research reproducibility;
- analytical traceability;
- preservation of original evidence;
- validation of scientific findings.

This section serves as the empirical foundation for all analytical conclusions presented in the research.
