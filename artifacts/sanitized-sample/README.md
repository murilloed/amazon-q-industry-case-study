# Synthetic Reproduction Sample

This directory contains an original, synthetic Java project. It represents a
small layered service without copying SARSB identifiers, business rules,
configuration, or generated prose.

The sample is suitable for validating:

- archive ingestion;
- JavaParser target discovery;
- manifest creation;
- JavaDoc insertion;
- report generation; and
- output organization.

It is not intended to reproduce the industrial system's domain complexity or
the focus-group findings.
