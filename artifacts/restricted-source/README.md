# Restricted Industrial Artifacts

The original SARSB input and complete generated output are intentionally absent
from the public repository.

| Artifact | Purpose | Public status |
|---|---|---|
| `sarsb-backend-main.zip` | Industrial Java input | Restricted |
| `sarsb-backend-main-2y8l9f-output.zip` | Full pipeline output | Restricted |

The checksums in `checksums.sha256` identify the exact archives used in the
audit. The inventory in `inventory.md` supports provenance and review without
exposing file contents.

No reader should attempt to reconstruct protected source code from published
results. Access is governed by `ACCESS.md`.
